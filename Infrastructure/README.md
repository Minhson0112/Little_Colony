The backend check suite passes 90 checks, and the CloudFormation template passes `cfn-lint` and AWS template validation. The updated WebGL build starts new villages with 1,000 acorns and no buildings, retains returning guest saves, and offers a confirmed guest restart in settings. Settings also open the Discord community invite. The domain/localization suite passes 2,835 checks; browser checks cover initial empty entry, buying a first home, reloading paid progress, canceling a restart, and confirming/reloading an empty restart. Build asset URLs carry content versions so returning browsers load updated files after CDN invalidation.

The generated `aws-template.json` provisions a private encrypted S3 bucket, a CloudFront HTTPS address, an ARM64 .NET 8 Lambda API, two retained DynamoDB tables, a runtime IAM role, and seven-day logs. It does not register or purchase a domain. Run `python Tools/create_aws_template.py` to regenerate the template.

The API role can get/put only game identities and snapshots, list table names for readiness, write its own logs, read encrypted provider settings, and persist encrypted session keys under the stack's Parameter Store path. No AWS access keys are created. The anonymous Lambda URL is gated by a private origin header injected by CloudFront; authenticated saves still require the player's session cookie and CSRF token. Canonical OAuth callbacks use `Hosting:PublicOrigin`, never a viewer-supplied forwarded host.

Build the API with `dotnet publish Backend/src/LittleColony.Api -c Release -r linux-arm64 --self-contained false -p:UseAppHost=false -o Builds/AwsDeploy/api`. ZIP that directory's contents as `api.zip`. Combine it with `aws-template.json`, `deploy.sh`, and the latest `Builds/WebGL` directory as `WebGL/` in a deployment bundle. Upload the bundle through the signed-in AWS CloudShell browser session, unpack into a fresh directory, and run `bash deploy.sh` after reviewing the resource and permission changes. The script provisions the stack, uploads assets with the correct WebAssembly MIME type, configures the generated HTTPS origin, and invalidates the CDN cache.

The default stack is `little-colony-production` in Sydney. Deployment parameters contain a private CDN token and must stay out of Git and public uploads. Existing parameters are retained on updates. Game tables and the asset bucket are retained if the stack is removed; deleting a stack is not a complete cleanup and must not be used to reset player progress.

Each DynamoDB table has 5 read and 5 write provisioned capacity units. Lambda has no provisioned concurrency or always-running server. This is intended for a small launch, not unlimited traffic. The generated CloudFront configuration uses pay-as-you-go pricing; no flat-rate subscription is automatically purchased. AWS free allowances depend on the account and combined usage. Storage, requests, encryption calls, logs, or traffic beyond allowances may still incur charges. A free AWS hostname does not guarantee zero hosting cost.

Provider credentials are not included in the bundle. Store existing credentials as Standard `SecureString` parameters at `/little-colony/little-colony-production/authentication/Facebook/AppId`, `Facebook/AppSecret`, `Discord/ClientId`, and `Discord/ClientSecret`, then recycle the Lambda execution environment. Register `https://<generated-host>/signin-facebook` and `/signin-discord` with the respective provider apps. A provider without configured credentials stays disabled. Public provider acceptance and returning authenticated cloud-save checks are required before announcing those features as live.
